| OLED 片选 | PA0～PA3 | 格 1～格 4 |
| OLED DC / RES | PB0、PB1 | 四块共用 |
| HX711 格 1 | PB5、PB8 | 数据脚 / 时钟脚 |
| HX711 格 2 | PB9、PB10 | 数据脚 / 时钟脚 |
| HX711 格 3 | PB11、PB12 | 数据脚 / 时钟脚 |
